# Student Performance Analysis using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing student academic performance across different training centers and learning modules using Microsoft Excel.

The analysis uses pre-test and end-test scores to evaluate student performance, identify improvement and decline patterns, compare center-wise results, and generate actionable insights.

Pivot Tables and Pivot Charts are used to summarize the data and present meaningful findings.

## 📂 Dataset Information

- **Total Student Records:** 1,960
- **Training Centers:** 6
- **Training Modules:** Cloud, IML, LR, Mobile Apps, Ana, SM
- **Performance Categories:** Decline, Fair, Good, Neutral, Very Good

### Dataset Columns
- Module Name
- Center Code
- End Test %
- Pre Test %
- Change in Scores
- Performance Category

## 🎯 Project Tasks

### Task 1: Center-wise Student Count
- Calculate the number of students who appeared for the End Test at each center.
- Summarize student participation using a Pivot Table.

### Task 2: Performance Category Distribution
- Calculate the percentage of students in each performance category.
- Visualize the distribution using a chart.

### Task 3: Center-wise Performance Analysis
- Calculate the count of different performance categories across centers.
- Analyze the percentage of Decline, Neutral, and Very Good students at each center.

### Task 4: Module-wise Decline Analysis
- Calculate the decline percentage for each module.
- Identify the module with the highest decline percentage.

### Task 5: Average End Test Scores
- Calculate average End Test scores for each module within each center.
- Compare academic performance across centers and modules using Pivot Tables.

### Task 6: Actionable Insights
- Identify the highest and lowest performing centers.
- Find the best and lowest performing modules.
- Recommend improvement strategies based on the analysis.

## 📊 Key Insights

- A total of 1,960 student records were analyzed.
- Good performance represents 31.53% of students.
- Very Good performance represents 27.50% of students.
- Decline accounts for 10.92% of overall performance categories.
- Cloud has the highest module-wise decline percentage at 16.47%.
- Odisha is the highest performing center with an average End Test score of 79.64%.
- Jharkhand is the lowest performing center with an average End Test score of 46.74%.
- The overall average End Test score is 70.64%.

## 💡 Actionable Recommendations

- Provide additional training and practice sessions for low-performing centers.
- Focus on improving Cloud module performance.
- Identify and share successful teaching practices from high-performing centers.
- Conduct regular assessments to monitor student progress.
- Provide targeted mentoring and doubt-clearing sessions.
